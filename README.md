# ブランド先生の出張買取 — コンペ提案デモ

50〜75歳女性を主な対象にした、出張買取ランディングページのデザイン提案です。

## 構成

- ファーストビュー：写真付きの査定品目4種／査定風景
- こんなお悩みはありませんか：4つの不安から該当セクションへ
- 状態別の相談例4件（スマホ2列）
- 買取実績の表示例4件（スマホ2列）
- ご利用の流れ4ステップ（仮案）
- お客様の声2件（架空の想定コメントと明記）
- よくあるご質問5件（開閉式・運用確認前の回答案）
- FAQ後に主な相談導線。追従ボタンも後半で表示し、フォーム閲覧時には非表示
- 申込フォーム体験：入力検証 → 内容確認 → 完了案内
- 審査者向けの設計意図・本番への引き継ぎ

## デモについて

写真はAI生成の仮素材、価格は架空の表示例、お客様の声は想定コメントです。実在の査定士・実績・口コミを示しません。費用・対応地域・キャンセル条件は未確定です。フォームは通信・保存をせず、個人情報の収集を行いません。実際の申し込みはできません。Google Fontsの読み込みを除き外部依存はありません。ブラウザで入力したデータを外部へ送信するコードや分析タグは含めていません。

## ローカル表示

`python3 -m http.server 4173 --bind 127.0.0.1`

http://127.0.0.1:4173/ を開きます。ビルド・依存パッケージは不要です。

## 公開

公開リポジトリのGitHub Pagesを使用。`main`ブランチのルートを公開元に指定します。有料サービス・有料ランナー・独自ドメインは使用しません。

## 本番実装

既存WordPressの買取実績・お客様の声の更新機能を維持する方針。支給写真、対象品目、査定士情報、価格、対応地域・費用、媒体掲載・限定条件、資料NO.2・NO.3、事業者情報、プライバシーポリシー、申込処理・通知先を確定したうえで実装します。

## 設計要点

スマホ対応、本文18pxを基準、大きな操作領域、キーボードフォーカス表示、入力エラーと完了案内。黄色・クリームと濃い文字色で親しみやすさと読みやすさを両立。
