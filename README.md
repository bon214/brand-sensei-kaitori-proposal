# ブランド先生の出張買取 — コンペ提案デモ

50〜75歳女性を主な対象にした出張買取ランディングページです。2026年9月25日に、FigmaのPC・スマホ修正案を反映しました。

## デザイン

- 元デザイン：https://www.figma.com/design/OEHmAk4qgpKI8OzLa3iUSa?node-id=9-442
- PC：1280px、スマホ：390pxのフレームに準拠。中間幅・小型スマホにも対応。
- 見出しはNoto Serif JP、本文・カード見出しはNoto Sans JP。Figmaの各指定に従って使い分け。
- 査定品目、悩み、状態例、買取実績、査定の3つの視点、写真付き4ステップ、お客様の声、FAQ、相談フォームの順に構成。
- PC・スマホで異なる文言と画像配置は、それぞれのデザインに合わせて切り替え。

## デモについて

写真・人物イラストはAI生成素材、価格は架空の表示例、口コミは想定文です。デザイン上のサービス説明・実績表現も提案用で、実際の営業情報を保証しません。費用・対応地域・キャンセル条件は本番公開前の確認が必要です。

フォームは入力検証、確認、完了の操作のみを行い、入力内容を外部へ送信・保存しません。実際の申し込みはできません。架空の情報でお試しください。Google Fonts以外の外部依存や分析タグはありません。

## ローカル表示

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

http://127.0.0.1:4173/ を開きます。ビルド・依存パッケージは不要です。
